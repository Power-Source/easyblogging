**Changes the ClassicPress administration area to include a beginner-friendly area by default, with the option to switch to the normal advanced area.**

## Customize and simplify the ClassicPress dashboard experience with Easy Blogging.

![A simpler ClassicPress dashboard experience.](https://psource.eimen.net/wp-content/uploads/sites/10/2026/04/easy-mode-735x470-1.jpeg)

### Custom style configuration

Include only the ClassicPress features that are needed using simple toggle controls. Choose from four themes with optional small icons and a custom Easy Blogging logo. Set up the ideal dashboard for your least experienced users.

![Choose the theme that best suits your needs.](https://psource.eimen.net/wp-content/uploads/sites/10/2026/04/theme-735x470-1.jpeg)

### Easy Mode

Give your users a one-click simplification of the ClassicPress dashboard. Enable Easy Mode to access wizard guidance, a streamlined dashboard, tooltips, and a custom dashboard widget.

![All the add-ons you need to create the perfect setup.](https://psource.eimen.net/wp-content/uploads/sites/10/2026/04/easy-add-ons735x470.jpeg)

### Earn more

Reduce support requests by enforcing Easy Mode for specific user types. Combine it with Multisite to lower the barrier to entry. Use the included PS MarketPress integration to simplify product creation, or enforce Easy Mode for free users in PS Bloghosting to encourage upgrades. Create an Easy Blogging experience that fits your customer base.
